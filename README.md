# Drakensig Golf Club

Website for Drakensig Golf Club, a 9-hole, 18-tee bushveld golf course inside AFB Hoedspruit, Limpopo, South Africa.

Live: https://obsidianstudiodesigns.github.io/Drakensig-Golf-Club/

- Static HTML, CSS and vanilla JS. No build step.
- Self-hosted fonts (Bricolage Grotesque, Hanken Grotesk), Phosphor icons.
- Tee time and enquiry form composes a WhatsApp message or email. Nothing is stored.
- Google Map only loads on request (POPIA friendly, no cookie banner needed).
- SEO: canonical, Open Graph (WhatsApp preview), JSON-LD GolfCourse schema, sitemap, robots.

Designed by [Obsidian Studio Designs](https://obsidianstudiodesigns.co.za/).
